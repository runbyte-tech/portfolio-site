Integration

Our SDK integrates with your existing stack in under five minutes. REST API, webhooks, and client libraries for every major language.

Node.js Python Go Ruby REST API
app.js 
import { RunByte } from '@runbyte/sdk';

const audit = new RunByte('your-api-key');

// Log any event with full context
await audit.log({
  action: 'document.updated',
  actor:  'user_2kF9xL',
  target: 'invoice_1042',
  metadata: {
    ip: '192.168.1.1',
    changes: ['amount', 'status']
  }
});
